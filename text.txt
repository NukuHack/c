Good news is that your exact request—a fixed-width character type like int32_t—was answered by the C standard itself, starting with C11.

🎯 The Solution: char32_t (and char16_t)

The C11 standard introduced two new character types specifically to solve the portability problem of wchar_t:

char32_t: This is exactly what you are looking for. It is an unsigned integer type that is guaranteed to be at least 32 bits wide.

char16_t: Similarly, this is an unsigned integer type guaranteed to be at least 16 bits wide, intended for UTF-16.

These types are defined in the <uchar.h> header.
